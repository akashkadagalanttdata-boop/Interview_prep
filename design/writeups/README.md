# Design writeups

One file per system, named `<system>.md`, from `templates/design.md`.

~25 systems across the design-first weeks: SD canonical designs (W15–17), ML canonical designs
(W22), and GenAI designs (W25).

Follow the 7-step loop **in order**. The order is the skill — jumping to boxes-and-arrows
before requirements is the most common way strong engineers lose design interviews.

At the end of each design-first week, compare your writeups and look for the reusable skeleton.
Finding that skeleton yourself is worth more than being handed a framework.
